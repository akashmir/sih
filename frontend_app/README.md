# NISHAN — Frontend

Cryptographic Attribution & Immutable Decryption Provenance System

Ministry of Defence — Indian Navy (WESEE)

## Setup

```bash
npm install
npm run dev
```

## Features

- Dashboard — System overview and health status
- Register Users — Generate post-quantum keypairs for recipients
- Distribute — Encrypt documents for multi-recipient distribution
- Decrypt — Recipient portal with invisible watermark injection
- Investigate — Forensic watermark extraction and attribution
- Audit Ledger — Tamper-evident hash chain explorer

## Tech Stack

- React + Vite
- Modern UI with government-style theme
